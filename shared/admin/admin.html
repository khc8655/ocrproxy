系统运行与可靠性参数

          
统一配置大模型路由策略、超时时钟、故障避让与系统运维

        


        
        

          
1. 运行模式与客户端鉴权 (Run Mode & Client Auth)

          

            

              

                客户端调用密钥 (PROXY_API_KEY)
                Cursor / Cline / Dify 调用 /v1/* 接口的 Authorization: Bearer 密钥
              

              

                
                
              

            

            

              

                系统运行模式 (Running Mode)
                控制管理后台页面自适应展示以及 /v1/models 的暴露范围
              

              

                
              

            

          

        


        
        

          
2. 核心分流调度策略 (Key Routing Strategy)

          

            

              

                Agent 模式分流策略 (agent_routing_strategy)
                智能体编程推荐「粘性故障转移」，保持会话连接与 KV Cache 稳定性
                

                  纯手动直通生效 系统直接使用各模型指定的当前激活 Key，禁用自动切换与熔断避让，上游响应 100% 原始透传。
                

              

              

                
              

            


            

              

                KB 知识库分流策略 (kb_routing_strategy)
                知识库无状态批量入库推荐「轮询负载均衡」，平摊并发压力
              

              

                
              

            

          

        


        
        

          
3. 超时时钟与重试预算 (Timeouts & Concurrency)

          

            

              

                首字节/等待超时 (upstream_timeout_sec)
                向上游发起请求等待首字节的时限（秒），超时切备用 Key
              

              

                
                秒
              

            

            

            

              

                单请求最大重试候选数 (max_retries)
                单次请求最多允许尝试的候选 Key 数量上限（默认 3 次）
              

              

                
                次
              

            


            

              

                单厂商最大尝试次数 (max_attempts_per_provider)
                单厂商多个 Key 故障时最多尝试次数（默认 2 次）
              

              

                
                次
              

            


            

              

                单 Key 最大并发保护 (max_concurrency_per_key)
                每个 API Key 在途最大并发保护，防止瞬间突发打崩配额
              

              

                
                个
              

            


            

              

                KB 大文件/OCR 处理超时 (upstream_timeout_kb)
                大图片 OCR 视觉识别与长文档解析时限（默认 60s）
              

              

                
                秒
              

            


            

              

                OCR 同时处理图片数 (ocr_max_inflight)
                前置限流并发处理图片数（超出的排队不占内存）
              

              

                
                张
              

            


            

              

                OCR 排队最长等待 (ocr_queue_timeout_sec)
                排队超过此时间返回 503 + Retry-After（默认 30s）
              

              

                
                秒
              

            


            

              

                跨厂商快速熔断 (fast_failover_provider_down)
                遇 502/504/连接超时且有其他可用厂商时，跳过当前厂商剩余 Key 立即切走
              

              

                
              

            

          

        


        
        

          
4. 容错熔断与冷却避让 (Fault Tolerance & Cooldowns)

          

            

              

                429 限流冷却时长 (cooldown_429_sec)
                命中 RPM/TPM 速率限制时的临时避让时长
              

              

                
                秒
              

            


            

              

                5xx 故障冷却时长 (cooldown_5xx_sec)
                上游 500/502/503/504 错误避让时长
              

              

                
                秒
              

            


            

              

                断路器熔断连续失败阈值 (circuit_break_threshold)
                单 Key 连续失败达到阈值即触发熔断（默认 3 次）
              

              

                
                次
              

            


            

              

                403 鉴权失败/欠费隔离 (cooldown_403_sec)
                Key 无效或额度用尽时的主动隔离时长
              

              

                
                秒
              

            

          

          

            ⚡ 纯手动直通模式：所有请求 100% 直连目标上游，不进行失败重试、熔断与冷却避让。
          

        


        
        

          
5. EdgeOne 凭据中枢与系统运维 (Vault Hub & Operations)

          

            

              

                EdgeOne 中枢服务地址
                云端金库中枢的基础访问 URL
              

              

                
              

            


            

              

                中枢访问 Token
                用于同步与拉取凭据的安全金钥
              

              

                
                
              

            


            

              

                中枢连通性诊断与增量同步
                测试中枢网络连接，或一键增量同步已配置的提供商端点与规则
              

              

                已配置凭证
                
                
              

            

            


            

              

                系统版本检测与平滑重启
                检查 GitHub 官方发行版本与 OTA 升级，或平滑重启网关守护进程
              

              

                
                
                
              

            

            

            

          

        


        
        

          
6. 底层配置管理与高级编辑 (Data & Raw JSON Config)
